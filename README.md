Приложение "Ремонт стиралок" для тех кто занимается ремонтом стиральных машин. Запись заявок, ввод симптомов, запись телефона с возможностью позвонить, запись адреса с возможностью нажать и сразу доехать до клиента (Яндекс карты строят маршрут) 
Подробный анализ дохода, учет запчастей, остаток, прайс и т.д. 😎
